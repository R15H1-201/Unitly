# Unitly 🔄

### A Simple, Interactive Unit Converter

**Unitly** is a clean and user-friendly web-based unit converter designed to make everyday unit conversions quick, understandable, and informative.

Instead of only showing the converted value, Unitly also provides the **SI base unit, conversion formula, and an interesting fact** related to the selected unit category.

🌐 **Live Demo:** [unitly-lime.vercel.app](https://unitly-lime.vercel.app/)

---

## ✨ Features

* 📏 **Multiple Unit Categories**

  * Length
  * Mass
  * Time
  * Temperature
  * Area
  * Volume
  * Speed

* 🔢 **Real-Time Conversion**

  * Enter a value and instantly calculate the converted result.

* 🔄 **Swap Units**

  * Quickly switch the "From" and "To" units.

* 📐 **SI Base Unit**

  * Displays the corresponding SI base unit for the selected category.

* ∑ **Conversion Formula**

  * Shows the formula used for the conversion to help users understand the calculation.

* 💡 **Fun Facts**

  * Displays interesting information and historical facts related to the selected unit category.

* 🌙 **Dark Mode**

  * Switch between light and dark themes.

* 📋 **Copy Result**

  * Copy the conversion result with one click.

* 🕘 **Conversion History**

  * View previous conversions through the History section.

* ℹ️ **About Section**

  * Provides information about the Unitly project.

* 📱 **Responsive Design**

  * Designed to work across desktop, tablet, and mobile screen sizes.

## 💻 How It Works

1. Select a **unit category**.
2. Enter the value you want to convert.
3. Select the **From** unit.
4. Select the **To** unit.
5. Click **Convert** or enter the value for automatic conversion.
6. Unitly displays:

   * Converted value
   * SI base unit
   * Conversion formula
   * Related fun fact

You can also swap the selected units using the **⇅** button.

## 🎯 Project Goal

The goal of Unitly is to create more than a basic conversion calculator.

The project focuses on making unit conversion:

* Easy to use
* Easy to understand
* Educational
* Fast
* Responsive
* Visually clean

By displaying formulas and facts alongside the result, Unitly helps users understand **how and why a conversion works**, rather than simply giving them a number.
